## 1. 路线判定

| 检查项 | 结论 |
|---|---|
| 是否内置语言系统（`i18n/`、`t()`、语言包） | 否。全局搜索 `i18n / locale / language / lang` 仅命中 `localeCompare` |
| 文本载体 | `game.js`（260 KB）内的数据表（`enemyData / itemData / skillData / questData / achievementData / settingsData`）与 `scenes` 静态方法中的模板字符串；`index.html` 静态标签与 `data-tooltip-*` |
| 文本是否参与逻辑 | 部分字段参与比较（天气 key、时间名、称号、场景 id），因此**只译展示值，不译 key** |
| 结论 | **路线 B：构建期源码补丁**（单文件、有完整源码、要求接近 100% 覆盖） + 双语双构建 |

未使用路线 O（运行时 DOM 覆盖），原因：本项目全部为 DOM 渲染且文本由模板拼接，运行时词典会漏掉 canvas 之外的日志/工具提示之外的动态拼接，且无法保证 100% 覆盖。

- 提取器为自写递归 JS 词法器（`localize/lexer.js`），可正确处理注释、引号转义、模板字符串嵌套 `${...}` 与嵌套模板。
- 结构校验：`{\...}` 链接标记的目标/参数序列逐条比对（剥除 `(行走文案)` 覆盖段），`\n` 数量、`${name}` 占位符数量必须一致 —— 当前不一致数 **0**。
- 翻译期间修正的典型缺陷：`saveName` 提示中的转义 `\" / \\` 必须保持转义层级，否则生成脚本语法错误（由 `node --check` 拦截并修复）。

## 3. 术语与译法

| 原文 | 译文 | 原文 | 译文 |
|---|---|---|---|
| Strength / Def / Spd / Dex | 力量 / 防御 / 速度 / 敏捷 | Energy | 体力 |
| Health / HP | 生命 | Experience / XP | 经验 |
| The Arena | 竞技场 | Hunters' Guild | 猎人公会 |
| Dojo | 道场 | golem / slime | 魔像 / 史莱姆 |
| Mastery | 精通 | Quest / Achievement | 任务 / 成就 |
| Els / Alan | 埃尔斯 / 艾伦 | Pointless（作者） | 保留原文 |

- 不译清单：物品/场景/技能/任务的内部 ID、`starterTown/forest` 等地区键、`G- ~ B+` 评级、`k/M/B/T` 大数后缀、`Arkivia`、`$`、`HP/XP` 缩写键（由 `ARK_WORDS` 在 UI 层显示中文全称）。
- 标点：译文统一使用全角冒号与中文引号，避免与 `{label|target}` 解析冲突；译文内不得出现裸 `|`、`{`、`}`（构建期已校验）。

## 4. 双构建与语言切换

- `dist/game.js`：上游原文 + 5 处共享补丁（英文）。
- `dist/game.zh.js`：共享补丁 + 653 处文案替换（中文）。
- `dist/index.html`：`document.write` 依据 `localStorage["arkivia-lang"]` 加载对应脚本，默认 `zh`。
- 入口：**设置 → 语言**（位于设置分类首位），切换写入 `localStorage` 后重载，存档保留。

## 8. 已知限制

1. `dist/changelog.html` 正文保留英文（仅顶部加中文说明）——更新日志属于发布说明，非游戏内 UI。
2. 英文存档首次载入中文版时，当前场景文本保持英文，直到切换场景或语言（重渲染逻辑仅在语言不匹配时触发）。
3. 少数由 `checks` 标识符派生、源数据无中文名的任务目标名（如未命名的 check）会显示英文标识符。
4. 背包角落的删除开关在中文下显示单字「删」（原版位置仅有 20px 宽），任务/成就等由 `checks` 标识符派生的条目名仍可能夹英文。
